🚀 نشر محتوى

📋 متطلبات كل منصة قبل ما النشر ينفع فعليًا

Facebook: Meta App + Page Access Token طويل الأجل.
Instagram: حساب Business/Creator مربوط بصفحة فيسبوك + Meta App معتمد.
Threads: نفس Meta App + صلاحيات Threads API.
TikTok: تطبيق مطور + اعتماد App Review لـ video.publish (بدونه الفيديو بينزل Draft فقط).
YouTube: Google Cloud Project + OAuth token بصلاحية youtube.upload.
X: اشتراك مدفوع (Basic فأعلى) — الـ Free tier مش بيسمح بالنشر.
WhatsApp: ⚠️ مفيش API رسمي للنشر في Channels لغاية دلوقتي — الرسمي الوحيد هو Business Cloud API لإرسال رسائل مباشرة.
